# gabrielrongyanglau.github.io

Personal academic website. Plain HTML and CSS, no build step.

- `index.html` – profile, research interests, selected publications, appointments, contact links
- `cv.html` – embedded curriculum vitae (`Gabriel_Lau_CV.pdf`) with download link
- `publications.html` – redirect to `index.html#publications` so old links keep working
- `styles.css` – shared stylesheet
- `Images/Profile Picture 1.jpg` – portrait used on the profile page (kept from the previous site)

To update the CV, replace `Gabriel_Lau_CV.pdf` with the new file (same name) and change the "Last updated" line in `cv.html`.
